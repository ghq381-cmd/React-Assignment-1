# React Assignment 1 🌍

A responsive React website showcasing beautiful natural wonders and famous places around the world, including Victoria Falls and scenic destinations in Pakistan.

## 🌐 Live Website

**Live Demo:** https://hassan-first-react.surge.sh

## 🚀 Technologies Used

- React.js
- Vite
- JavaScript (JSX)
- HTML5
- CSS3
- Google Fonts (Poppins)
- Git & GitHub
- Surge.sh (Hosting)

## ✨ Features

- Responsive website layout
- Beautiful nature and travel images
- Information about Victoria Falls
- Beautiful Places in Pakistan section
- Clean typography using Poppins
- Dark background with white text
- Mobile, tablet, and desktop support

## 💻 Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/ghq381-cmd/React-Assignment-1.git
```

**2. Open the project folder**

```bash
cd React-Assignment-1
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 📦 Production Build

```bash
npm run build
```

## 🌐 Deployment

This project is deployed using Surge.sh.

```bash
npm run build
surge ./dist hassan-first-react.surge.sh
```
